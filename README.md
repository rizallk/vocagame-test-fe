# Front End Developer Technical Test - VocaGame

## Dibuat Oleh Mohalim Rizal Kadamong (Rizal)

### Tech Stack

- <b>ReactJS + TypeScript</b>
  </br>
  Digunakan sebagai teknologi web front end utama (core).
- <b>TanStack Query (React Query) + Axios</b>
  </br>
  Digunakan sebagai data fetching. Dipilih karena menyediakan teknologi canggih seperti caching, refetching, dan lain-lain.
- <b>Radix UI (Primitive) + TailwindCSS</b>
  </br>
  Digunakan sebagai komponen UI dasar (Radix) dan melakukan styling UI, layout, dan beberapa kustomisasi komponen lainnya (Tailwind). Dipilih agar bisa secara bebas menyesuaikan dengan desain UI/UX.
- <b>Zustand</b>
  </br>
  Digunakan sebagai state management/global state. Dipilih karena populer dan mudah digunakan.
- <b>React Router (Declarative Mode)</b>
  </br>
  Digunakan sebagai routing. Dipilih karena populer dan mudah digunakan.
- <b>Recharts</b>
  </br>
  Digunakan sebagai Area Chart, Pie Chart dengan kustomisasi tingkat lanjut. Dipilih agar supaya sesuai dengan desain UI/UX.
- <b>Vite</b>
  </br>
  Digunakan sebagai build tool dan bundler. Dipilih karena populer dan cepat untuk project ReactJS modern.

## Requirements

Untuk dapat menjalankan project ini, pastikan beberapa hal ini ada di mesin/perangkat/komputer Anda :

1. <b>NodeJS</b> ^v.22
2. <b>NPM</b> ^v.10

## Installation

Clone project ini dan jalankan perintah berikut di terminal / CMD Anda :

`npm install`

Setelah itu jalankan perintah berikut ini untuk melakukan build :

`npm run build`

Nyalakan project dengan perintah berikut ini :

`npm run preview`
